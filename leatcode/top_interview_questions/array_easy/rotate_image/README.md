# 📝 LeetCode 48. Rotate Image (핵심 풀이: Transpose & Reverse)

## 1. 접근 방법: 기하학적 변환
90도 회전을 복잡한 인덱스 계산 없이, **두 번의 단순한 변환**으로 해결하는 방법입니다.

이 방법은 **"가로줄을 세워서(전치), 오른쪽으로 보낸다(반전)"**는 논리를 사용합니다.

---

## 2. 단계별 상세 과정

### 1단계: Transpose (전치) - "줄 세우기"
행렬의 **주 대각선(왼쪽 위 $\searrow$ 오른쪽 아래)**을 축으로 접었다 펴는 과정입니다.
- **동작**: `행(Row)` 데이터를 `열(Column)` 데이터로 변환합니다.
- **인덱스**: `matrix[i][j]`와 `matrix[j][i]`를 교환.

### 2단계: Reverse (반전) - "제자리 찾기"
각 행(Row)의 좌우 순서를 뒤집습니다.
- **동작**: 왼쪽(Left)에 쏠려 있던 데이터를 오른쪽(Right)으로 이동시킵니다.
- **인덱스**: 한 행 안에서 `start`와 `end` 포인터 값을 교환.

---

## 3. 시각적 예시 (3x3 Matrix)

**[초기 상태]**
```text
1  2  3  ← (맨 윗줄)
4  5  6
7  8  9

```

**[Step 1: Transpose]** 대각선 `[1, 5, 9]`는 고정, 나머지는 맞교환

```text
1  4  7  ← (맨 윗줄이 왼쪽 기둥이 됨)
2  5  8
3  6  9

```

> **상태**: 90도 회전은 되었지만, 좌우가 거울처럼 반대로 되어 있습니다.

**[Step 2: Reverse]** 각 줄을 좌우 반전

```text
7  4  1  ← (왼쪽 기둥이 오른쪽으로 이동!)
8  5  2
9  6  3

```

> **결과**: 완벽하게 시계방향 90도 회전 완료.

## 4. 코드 구현 (Python)

```python
class Solution:
    def rotate(self, matrix: list[list[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)
        
        # ------------------------------------------------
        # 1단계: Transpose (전치)
        # 대각선 윗부분만 순회하며 대각선 아래와 맞바꿉니다.
        # ------------------------------------------------
        for i in range(n):
            # j는 i + 1부터 시작해야 중복 교환(바꾼 걸 또 바꾸기)을 방지합니다.
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        
        # ------------------------------------------------
        # 2단계: Reverse (좌우 반전)
        # 각 행을 순회하며 리스트를 뒤집습니다.
        # ------------------------------------------------
        for row in matrix:
            # Python의 내장 함수를 사용하여 In-place 반전
            row.reverse()
            # 만약 직접 구현한다면: l, r = 0, n-1 반복문 사용

```

## 5. 복잡도 분석

* **시간 복잡도**: 
* 전치 과정에서 약 번 연산, 반전 과정에서 번 연산하므로 전체 에 비례합니다.


* **공간 복잡도**: 
* 추가적인 행렬을 만들지 않고 기존 `matrix` 안에서 교환만 일어납니다 (In-place).
